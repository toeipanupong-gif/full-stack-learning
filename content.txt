8. AI for Software Development

เมื่อเรียนจบแล้ว จะเข้าใจวิธีใช้ AI ช่วยงานพัฒนา Software ตั้งแต่การวิเคราะห์ Requirement, เขียน/รีวิว/Debug Code, ออกแบบระบบ, เขียน Test และช่วยค้นปัญหาได้อย่างมีประสิทธิภาพ พร้อมรู้ข้อจำกัดและความเสี่ยงของ AI เช่น Hallucination, Code ที่ผิดหรือไม่ปลอดภัย, Dependency/ข้อมูลที่ล้าสมัย และการรั่วของ Secrets/ข้อมูลลูกค้า ที่สำคัญคือจะรู้วิธีใช้ AI แบบ Assistant, not Authority


8.1 AI for Software Development Fundamentals
Topic 8 เราจะเรียนทั้งหมด 10 บท โดยแกนหลักคือการใช้ AI ให้ช่วยเพิ่มความเร็วในการพัฒนา Software โดยไม่ทำให้คุณภาพ Code, Security หรือความเข้าใจระบบลดลง

Mental Model ที่ต้องจำตั้งแต่ต้นคือ:
AI = Assistant
Developer = Decision Maker

หรือพูดง่าย ๆ ว่า:
AI ช่วยคิด ช่วยเสนอ ช่วยเขียน และช่วยตรวจได้ แต่ Developer ต้องเป็นคนตัดสินใจและรับผิดชอบผลลัพธ์สุดท้าย

1) AI ช่วย Software Developer ได้เรื่องอะไรบ้าง
AI สามารถช่วยงานได้หลายประเภท เช่น:
Requirement Analysis
Code Generation
Code Review
Debugging
Refactoring
Testing
Documentation
System Design
SQL

แต่ความเหมาะสมไม่เท่ากันทุกงาน
2) งานที่ AI ทำได้ดี
โดยทั่วไป AI เหมาะกับงานที่:
มี context ชัด
มี pattern ชัด
ตรวจผลลัพธ์ได้

เช่น:
สร้าง CRUD
เขียน validation schema
สร้าง test case
อธิบาย error

เขียน SQL เบื้องต้น

4) แต่ AI ไม่รู้ระบบเราทั้งหมดโดยอัตโนมัติ

25) Example

เช่น:

อย่า refactorส่วนอื่น

49) แต่ Documentationต้อง Verify
